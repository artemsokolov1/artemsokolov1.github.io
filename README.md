# artemsokolov1.github.io

Персональная визитка Артёма Соколова — AI-разработчика из Новосибирска.
Одна компактная карточка: кто я, разделы «Игры» и «Сервисы», донат и контакты.
Подробности по каждому проекту раскрываются кликом по строке.

Статика без сборки и зависимостей: HTML + CSS + немного JS.

## Структура

```
index.html              вся страница
assets/css/style.css    стили, тёмная и светлая темы
assets/js/main.js       тема, аккордеон, копирование кошелька
assets/img/favicon.svg  иконка сайта
assets/img/artem.jpg    ваше фото (добавьте сами)
.nojekyll               отключает Jekyll на GitHub Pages
```

## Публикация на GitHub Pages (бесплатно)

1. Создайте на GitHub **публичный** репозиторий с именем ровно `artemsokolov1.github.io`
   — оно должно совпадать с вашим username, тогда сайт откроется по адресу
   https://artemsokolov1.github.io/
2. В этой папке выполните:

   ```bash
   git init
   git add .
   git commit -m "Портфолио: первая версия"
   git branch -M main
   git remote add origin https://github.com/artemsokolov1/artemsokolov1.github.io.git
   git push -u origin main
   ```

3. В репозитории: **Settings → Pages**, источник — `Deploy from a branch`,
   ветка `main`, папка `/ (root)`.
4. Через 1–2 минуты сайт будет онлайн. Дальше любой `git push` в `main` обновляет его.

## Что нужно заполнить

Все места помечены в `index.html` комментарием `ЗАМЕНИТЕ`:

- **Фото** — положите `assets/img/artem.jpg` (квадрат, от 400×400).
  Пока файла нет, вместо него показываются инициалы «АС».
- **Мини-описания** — строки `<p class="note">Место для вашего описания.</p>`
  внутри каждого проекта.
- **Домен игры** — в блоке «Первая игра» раскомментируйте строку `<a class="go" …>`
  и впишите домен; заодно поменяйте `dot--soon` на `dot--live` и текст `скоро`.
- **Контакт** — ссылка на Telegram в подвале (`https://t.me/username`).

## Добавить проект

Скопируйте любой блок `<details class="item">` в нужную секцию. В разделе «Игры»
готовый шаблон уже лежит в HTML-комментарии. Статус задаётся классом точки:

| Класс        | Значение     |
|--------------|--------------|
| `dot--live`  | работает     |
| `dot--dev`   | в разработке |
| `dot--soon`  | скоро        |

## Локальный просмотр

Откройте `index.html` в браузере или поднимите сервер:

```bash
python -m http.server 8000
```
